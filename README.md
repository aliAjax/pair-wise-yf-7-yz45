# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、校样替字、逐格确认放行、保存草稿并导出 PNG 预览图。

## 校样与放行闭环

- 每处落字默认 **待校**，格子右下角金点标识；点击已有字的格子打开校样弹窗。
- 可对格子 **标记磨损**，并从 **同字不同风格** 的字模中选择替换：
  - 替换成功后，原字模余量释放、替字模占用增加，格子重新回到待校；
  - 若替字模余量不足，**整次拒绝**，版面、余量与校样状态都不变。
- 弹窗内逐格 **确认此格**；全部格子确认后版面自动 **放行**（绿点 + 放行徽章），此时才允许导出 PNG。
- 放行后再新增、移动（拖拽格内字模）或移除落字，涉及格子退回待校，放行失效；移除导致无“涉及格”可退回时，版面其余格子整体退回待校。
- 草稿保存每格的待校/已确认与磨损状态；旧草稿缺少状态字段时，载入按 **待校** 处理。
- 字模卡片余量、缺字提醒、校样进度、草稿列表与 `localStorage` 同步，刷新后保留。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问，无构建步骤、无外部依赖。
