# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、逐格校样（标记磨损、同字不同风格替字）、全部确认后放行并导出 PNG 预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问（如 `python3 -m http.server`）。无新增页面、无第三方依赖、无后端服务，数据仅存于浏览器 `localStorage`。

## 校样与放行闭环

- 每处落字默认为**待校**（金色角标），点击已落字的格子打开校样弹层。
- 可勾选**标记磨损**（红色斜杠与角标），并从弹层中选择**同字不同风格**的字模一键替换。
- 替换为原子操作：先释放原字模余量、再占用替字模；若替字模余量不足，**整次拒绝**——版面、字模余量、磨损标记与校样状态都保持不变，并给出错误提示。
- 在弹层或右侧"逐格校样"列表中逐格确认（绿色角标），可随时撤回。
- 只有**全部格子确认**后"放行版面"按钮才可点击；放行后"导出预览图"才可用（未放行时导出按钮禁用）。
- 放行后若新增、移动（已落字的格子可整体拖动，拖到占用格则两格交换）、替字或移除落字，放行立即失效、导出重新禁用，**仅涉及格子退回待校**，其余格子保留确认状态，需重新逐格确认后放行。
- 字模卡片实时显示"已用/总量"与余量，超量落字只做**缺字提醒**（顶部徽标与右侧缺字清单），不拦截落字；整次拒绝仅适用于磨损替字。
- 保存草稿时写入每格的校样状态与磨损标记；载入旧草稿缺少状态字段时一律按待校处理。
- 字模余量、缺字提醒、草稿列表与本地存储实时同步，刷新页面后状态保留。
